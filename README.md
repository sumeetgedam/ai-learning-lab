
# AI Engineering Lab : From Classical ML to Production AI Systems

## AI Engineering Lab

A hands-on end-to-end AI Engineering journey covering  Machine Learning, Embeddings, Semantic Search, Retrieval-Augmented Generation (RAG), Tool Calling Agents, Production Retrieval Systems and AI Evaluation

The Objective of this repository is to udenrstand mordern AI systems from first principles by progressively building every major layer rather than relying on hgih-level frameworks.
